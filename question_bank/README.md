# Question banks

The project target is 500 questions total:

- Easy: 180
- Medium: 170
- Hard: 150

Each scenario has `questions.csv`, `answers.csv`, and `hints.csv`. Easy currently contains the validated 25-question starter bank. Medium/Hard deliberately contain schemas only until their distinct campaign data exists and passes the same Splunk parser/CIM validation used for Easy.

Participant exports are generated separately and must never include answers or reference SPL.
