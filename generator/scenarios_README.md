# Scenario modules

`config/scenarios/*.json` is the authoritative scenario registry.

- `easy`: validated and generated by the current Easy campaign implementation.
- `medium`: authoring gate. Do not mark validated until its distinct attack module, questions, and Splunk TA/CIM checks pass.
- `hard`: authoring gate. Same requirement.

All new scenario modules must use `generator.core.scenario.ScenarioContext` for time placement and must keep events inside the configured UTC window.
